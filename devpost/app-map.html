Main pieces

Edit

App coordinates the workspace. FloorplanCanvas projects footprints into isometric view; placement validation and the reducer accept changes and retain Undo.

Simulate

useSimulation advances fixed engine ticks. The café model keeps customers, seats, orders and staff separate. Playback speed changes presentation, not the scenario.

Compare & recover

Completed baseline/latest snapshots carry their own layouts. Results and diagnostics use those snapshots. storage.js validates browser-local saves; no backend or runtime AI service is involved.

Reference route · three stops

This route is for future navigation; it does not claim an interactive code tour was completed.

  1. Define and apply the controlled change

    src/app/caseStudy.js · caseStudy, identifyCaseVariant
    src/app/workspace.js · workspaceReducer, APPLY_CASE_B

    A and B clone the same 12-seat inventory. Only pickup moves from (8, 2)m to (5, 2)m. Applying B adds one Undo step and retains the baseline; starting the example clears results only after the UI's confirmation.

  2. Run, then capture evidence

    src/app/useSimulation.js · useSimulation, start
    workspaceReducer · RUN_COMPLETED

    The runner uses createRun → step → finish, then dispatches a completed snapshot. Stop/error preserve earlier results. createSaveDocument / loadWorkspace save and validate recoverable data; no partial run is saved.

  3. Explain and locate the result

    src/simulation/diagnostics.js · deriveDiagnostics
    src/App.jsx · showDiagnostic

    The pure calculation separates production queue from preparation/delivery for the same produced orders, then ranks connected blocked-travel cells. FlowDiagnostics shows evidence; ComparisonPanel keeps completion and capacity context first. Missing historical timing stays unavailable.

To change this, start here

  • Preset seating or the A/B position: cafePresets and caseStudy.layouts. Check access, fixed demand and capacity before interpreting metrics.
  • Diagnostic definitions: deriveDiagnostics and tests/diagnostics.test.js. Preserve the produced-order denominator and unavailable-data behavior.
  • Floor rendering or hit areas: FloorplanCanvas, isometric.js, and Furniture. Artwork height is presentation; footprints remain physical geometry.
  • Furniture facing the wrong direction: artForFurniture selects quarter-turn crops from furniture-atlas.json. The chair-frame regression in tests/artwork.test.js protects the visually audited south/west/north/east sequence for all three themes.
  • Spacing and results copy: src/styles.css, FlowDiagnostics and ComparisonPanel. Retain preview identity, failure cautions, keyboard focus and the fixed heat scale.

A practice to reuse

Turn “make the layout better” into one observable question: keep demand and 12 seats fixed, move only pickup, and compare completion before time savings.

In the measured model, A and B both complete 24/24 journeys and fulfill 12/18 dine-in requests. B reduces order-to-ready from 314.3s to 250.9s and barista travel from 240m to 96m, while movement obstruction rises from 2.0% to 3.2%. This is a trade-off, not a universal winner.

tests/caseStudy.test.js verifies equal inventory, a single changed object, determinism and non-mutating diagnosis. tests/e2e/diagnostics.spec.js exercises the visible A/B journey, preview identity, recovery and locks. Use the same pattern elsewhere: fixed inputs → one change → executable check → qualified conclusion.

What this evidence does not establish

The model uses illustrative demand, service times, role zones and shared seating. The public-plan case study records source facts separately from adaptations. Neither the example nor automated browser checks establish real café performance or café-user validation.

Run again

From the repository root, use the recorded Node 24.22.0 runtime. Dependencies are pinned in the lockfile.

npm ci
npm run dev -- --host 127.0.0.1 --port 5173 --strictPort

Open http://127.0.0.1:5173. For a built preview, run:

npm test
npm run test:e2e
npm run build
npm run preview -- --host 127.0.0.1 --port 4173 --strictPort

Playwright needs Chromium installed (npx playwright install chromium if needed). Browser-local saves belong to their origin; localhost and 127.0.0.1 have separate storage.
