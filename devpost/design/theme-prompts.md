# Final theme artwork prompts

Generated with the built-in `image_gen` tool, no CLI/API fallback. Final selected PNGs are preserved unchanged in `src/assets/`. The earlier nine-row probes were rejected because the cells were too crowded; they are not bundled. Each theme uses three independent 4-column × 3-row atlases. Transparent alpha is retained; crop coordinates/quarter-turn ordering/ground anchor are recorded in `src/assets/furniture-atlas.json`. Source columns were inspected and reordered where necessary to align long edges with world orientation; sprite image planes are never rotated.

Use case: stylized-concept. Transparent production game sprite atlas, landscape image, EXACTLY FOUR COLUMNS AND THREE ROWS, 12 sprites. Fixed 2:1 orthographic isometric camera, world +x slopes down-right, world +y down-left. Upright verticals. ROW 1: one standalone rectangular TABLE (1.5x1m), NO chairs or objects attached; ROW 2: one single CHAIR (0.5x0.5m); ROW 3: one two-seat BENCH (2x0.5m). Each ROW is the SAME furniture at four clockwise orientations; same design/materials in all four views. Column1 rotation0: front faces bottom-left, long edge slopes DOWN-RIGHT (\\). Column2 rotation90: back seen, front faces top-left, long edge slopes DOWN-LEFT (/). Column3 rotation180: back seen, front faces top-right, long edge slopes DOWN-RIGHT (\\). Column4 rotation270: front faces bottom-right, long edge slopes DOWN-LEFT (/). Thus long edges ALTERNATE \\, /, \\, /. Turn objects in world space, never rotate the picture plane. Furniture material style: JAPANDI: natural pale oak, rounded joinery, upholstered muted sage seats, ivory fluted timber counters, minimal ceramic planters, warm brushed brass bin. Realistic material detail in fine semi-pixel management game style. Soft low-contrast ambient daylight from upper left. Actual transparent alpha background, no opaque backdrop. Each sprite centered in its own equal cell, fills ONLY 60% CELL WIDTH and maximum 65% CELL HEIGHT. Leave at least 15% EMPTY TRANSPARENT PADDING on ALL FOUR sides of EVERY cell. NO sprite/shadow may touch another row or column; no cropping. Complete feet/bases fully visible. No floor patches, extra objects, attached chairs, people, labels, gridlines, borders or watermark.
